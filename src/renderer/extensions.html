Extensions

Electron supports a subset of the Chrome extension API. This page shows what each one gets.

What works, what does not

Works

  • content scripts (all frames, run_at, matches)
  • MV2 background page, event pages
  • chrome.storage.local / sync (local disk, no sync)
  • chrome.runtime.sendMessage / connect / onMessage
  • chrome.tabs.sendMessage, reload, executeScript (partial query)
  • chrome.scripting, chrome.i18n, chrome.management (partial)
  • DevTools extensions — full API, panels included
  • observational chrome.webRequest

Does not work

  • MV3 service-worker background (loads as an inert page)
  • blocking webRequest / declarativeNetRequest → no real ad blocking
  • chrome.action / browser_action toolbar popups (this shell opens them in a window instead)
  • chrome.windows, bookmarks, history, downloads, cookies, notifications, alarms
  • sidePanel, omnibox, contextMenus, tabGroups
  • installing straight from the Chrome Web Store (use .crx or an unpacked folder)
